Activate new locations

Generate and add an upcoming batch now, even when a current set is not finished. Only submitted responses inform the adaptive part; unfinished locations are not treated as neutral.

A batch is appended after the locations already assigned to each participant. Each receives one location per pair, in independently randomized order. To avoid accidentally stacking work, an unstarted future batch prevents another activation.

Activation is a real change to the study when this page is eventually deployed. This development version must not be connected to production until separately tested and approved for deployment.
